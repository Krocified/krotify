# krotify v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shippable Android music player that scans every audio file on the device, plays it with background playback and lock-screen/notification controls, and looks like a premium music app.

**Architecture:** One React Native screen tree with a single animated screen state (Library ↔ Now Playing ↔ Settings), no navigator. Pure logic (hashing, formatting, track mapping, mock clock) lives in `src/lib/` and is tested with Node's built-in test runner. One `expo-audio` player instance owns playback for the whole app; a provider exposes it to screens and swaps in a timer-based mock engine for demo tracks. `expo-media-library` supplies the library in pages of 200, with playable URIs resolved lazily at play time.

**Tech Stack:** Expo SDK 58, React Native 0.88, TypeScript strict, `expo-audio`, `expo-media-library`, `expo-linear-gradient`, `react-native-safe-area-context`, RN `Animated`, Node 24 `node --test`.

**Spec:** `docs/spec.md` (read it with this plan; the plan argues from the spec)

## Global Constraints

- Android only. Every milestone runs on a real device.
- Dev build required from v0: `npx expo run:android --device`. Expo Go cannot apply the `expo-audio` config plugin.
- Background playback and lock-screen/notification controls are v0 requirements, not v1.
- Scan all `MediaType.AUDIO` assets. No duration filter, no file-type filter.
- v0 shows filename-derived titles only. No artist column, no ID3 tags.
- Sort the library A→Z by title (`localeCompare`), dedupe by asset id.
- Demo library is the only fallback: permission denied, zero audio files, or scan error.
- No "Recently played" rail in v0, no seeded history.
- No navigator. One animated `screen` state: `'library' | 'nowPlaying' | 'settings'`.
- New dependencies limited to: `expo-audio`, `expo-media-library`, `expo-linear-gradient`, `react-native-safe-area-context`; dev-only `@types/node`.
- Design tokens come from the spec verbatim: `bg #0B0B0F`, `surface #16161D`, `surfaceHi #1F1F29`, `text #F5F5F7`, `textDim #9A9AA8`, `accent #7C5CFF`, `accent2 #FF6B57`.
- Generated covers only in v0: deterministic gradient from hash + title initial, 4px radius (8px large screens). No grain, no blur, no overlay on art.
- Commit at the end of every task. Conventional Commits, imperative, ≤50-char subject.
- Run `npm test`, `npx tsc --noEmit`, and `npx expo lint` before claiming any task done.

## Review Focus

1. **Permission races.** Permission denied, revoked mid-scan, or granted with zero audio: the app must land on the demo library and never render a broken list or crash.
2. **Stale or missing files.** A scanned file deleted or moved before play: skip it, show an inline message, keep the current track playing. Never wedge the player.
3. **Large libraries.** 5,000+ audio files: paging keeps the UI responsive, `FlatList` virtualizes, and no per-asset native call happens for off-screen rows.
4. **Background survival.** Screen locked for 3+ minutes: audio keeps playing and notification controls still drive it. This fails silently if `setActiveForLockScreen` or the config plugin is missing.
5. **Rapid track switching.** Tapping track B while track A's URI is still resolving must not let A's status overwrite B. Every async play is guarded by a request id.

```ts
export function hashString(input: string): number {
  let hash = 2166136261;
  for (let i = 0; i < input.length; i += 1) {
    hash ^= input.charCodeAt(i);
    hash = Math.imul(hash, 16777619);
  }
  return hash >>> 0;
}

export function hueFromSeed(input: string): number {
  return hashString(input) % 360;
}
```

```ts
export function formatDuration(ms: number): string {
  if (!Number.isFinite(ms) || ms <= 0) return '0:00';
  const totalSeconds = Math.floor(ms / 1000);
  const seconds = totalSeconds % 60;
  const minutes = Math.floor(totalSeconds / 60) % 60;
  const hours = Math.floor(totalSeconds / 3600);
  const ss = String(seconds).padStart(2, '0');
  if (hours > 0) return `${hours}:${String(minutes).padStart(2, '0')}:${ss}`;
  return `${minutes}:${ss}`;
}

export function titleFromFilename(filename: string): string {
  const withoutExtension = filename.replace(/\.[a-z0-9]{1,5}$/i, '');
  const withoutTrackNumber = withoutExtension.replace(/^\s*\d{1,3}\s*[-._)\]]+\s*/, '');
  const cleaned = withoutTrackNumber.replace(/_+/g, ' ').replace(/\s+/g, ' ').trim();
  return cleaned || 'Untitled';
}
```

```ts
import type { Track } from '../types';
import { titleFromFilename } from './format';
import { hueFromSeed } from './hash';

export type AssetMeta = { id: string; filename: string; durationMs: number };

export function toTrack(meta: AssetMeta): Track {
  const title = titleFromFilename(meta.filename);
  return {
    id: meta.id,
    uri: '',
    source: 'scan',
    title,
    artist: '',
    album: '',
    durationMs: meta.durationMs,
    artworkHue: hueFromSeed(meta.filename),
  };
}

export function sortTracks(tracks: Track[]): Track[] {
  return [...tracks].sort((a, b) => a.title.localeCompare(b.title, undefined, { sensitivity: 'base' }) || a.id.localeCompare(b.id));
}

export function mergeTracks(existing: Track[], page: Track[]): Track[] {
  const seen = new Set(existing.map((t) => t.id));
  const additions = page.filter((t) => !seen.has(t.id));
  return [...existing, ...additions];
}

export function tracksFromPage(metas: AssetMeta[]): Track[] {
  return sortTracks(mergeTracks([], metas.map(toTrack)));
}
```

```ts
import { AudioPlayer, createAudioPlayer, requestNotificationPermissionsAsync, setAudioModeAsync } from 'expo-audio';
import { Platform } from 'react-native';
import type { Track } from '../types';

export const audioPlayer: AudioPlayer = createAudioPlayer(null, {
  updateInterval: 500,
  keepAudioSessionActive: true,
});

export async function configureAudio(): Promise<void> {
  await setAudioModeAsync({
    playsInSilentMode: true,
    shouldPlayInBackground: true,
    interruptionMode: 'doNotMix',
  });
  if (Platform.OS === 'android') {
    try {
      await requestNotificationPermissionsAsync();
    } catch {
    }
  }
}

export async function playAudio(uri: string, track: Track): Promise<void> {
  audioPlayer.replace({ uri });
  audioPlayer.setActiveForLockScreen(
    true,
    { title: track.title, artist: track.artist || undefined, albumTitle: track.album || undefined },
    { showNextTrack: false, showPreviousTrack: false, showSeekBackward: true, showSeekForward: true },
  );
  audioPlayer.play();
}

export function pauseAudio(): void {
  audioPlayer.pause();
}

export async function seekAudio(positionMs: number): Promise<void> {
  await audioPlayer.seekTo(positionMs / 1000);
}
```

- [ ] **Step 2: Implement `PlayerProvider`**

Rules:
- `configureAudio()` once on mount, errors swallowed into `lastError`.
- `useAudioPlayerStatus(audioPlayer)` supplies real-track status.
- `mode: 'audio' | 'mock' | null`; demo tracks always use `mode: 'mock'`.
- Mock engine: `setInterval(250)` advancing `mockTick`; clear on pause, seek, track change, unmount.
- `playTrack(track, resolveUri)`:
  1. `const requestId = ++requestRef.current`
  2. demo → `setMode('mock')`, reset mock position to 0, `setMockPlaying(true)`, `setTrack(track)`, return `true`
  3. otherwise `await resolveUri(track)` inside try/catch
  4. after await: if `requestId !== requestRef.current` return `false` (stale tap)
  5. `await playAudio(uri, track)`, `setMode('audio')`, `setTrack(track)`, clear `lastError`, return `true`
  6. on throw: `setLastError('Could not play this file')`, return `false` (current track untouched)

- [ ] **Step 2: Write `src/library/scan.ts`**

```ts
import { Asset, AssetField, MediaType, Query, requestPermissionsAsync } from 'expo-media-library';
import type { Track } from '../types';
import { tracksFromPage } from '../lib/library';

const PAGE = 200;

const baseQuery = () =>
  new Query()
    .eq(AssetField.MEDIA_TYPE, MediaType.AUDIO)
    .orderBy({ key: AssetField.CREATION_TIME, ascending: false });

export async function ensureAudioPermission(): Promise<boolean> {
  const response = await requestPermissionsAsync(false, ['audio']);
  return response.granted;
}

export async function scanLibrary(): Promise<{ tracks: Track[]; assets: Map<string, Asset> }> {
  const metas: { id: string; filename: string; durationMs: number }[] = [];
  const assets = new Map<string, Asset>();

  for (let offset = 0; ; offset += PAGE) {
    const [pageAssets, pageMetadata] = await Promise.all([
      baseQuery().offset(offset).limit(PAGE).exe(),
      baseQuery().offset(offset).limit(PAGE).exeForMetadata(),
    ]);
    if (pageAssets.length === 0) break;
    for (const asset of pageAssets) assets.set(asset.id, asset);
    for (const meta of pageMetadata) {
      metas.push({
        id: meta.id,
        filename: meta.filename ?? '',
        durationMs: Math.round(meta.duration ?? 0),
      });
    }
    if (pageAssets.length < PAGE) break;
  }

  return { tracks: tracksFromPage(metas), assets };
}
```

Duration note: on Android, `AssetMetadata.duration` is MediaStore milliseconds (source-verified). Task 9 verifies this against a known file; if it turns out to be seconds, multiply by 1000 in the mapping loop and note it here.

```ts
async function loadLibrary() {
  setStatus('scanning');
  setStatusNote(null);

    if (!(await ensureAudioPermission())) {

  }

  else setScreen('nowPlaying');
```
