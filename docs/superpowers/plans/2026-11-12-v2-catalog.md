# v2 Catalog Implementation Record

**Status:** delivered (catalog UI); playlist and favorite UI remain.

**Spec:** `docs/spec.md` v1/v2 sections.

## Delivered

- **Metadata:** `@missingcore/react-native-metadata-retriever@4.0.0-beta.2`
  bulk reads in chunks of 50, cached in SQLite (`track_metadata`). Filename
  titles remain the fallback. Artwork loads lazily via `saveHashedArtwork` and
  propagates through `tracks` so list rows, heroes, recent rail, mini-player and
  Now Playing share the same image.
- **SQLite:** `expo-sqlite` singleton with `PRAGMA user_version` migrations.
  Tables: `playlists`, `playlist_tracks` (gap positions), `favorites`,
  `play_history`, `track_metadata`. Web uses a no-op stub.
- **Groups and search:** pure helpers in `src/lib/groups.ts` and
  `src/lib/search.ts`, with tests. Albums key on `albumArtist|album`; artists
  aggregate album counts; search folds accents and covers title/artist/album.
- **Navigation:** state tabs in `AppShell` (Library, Albums, Artists); Settings
  and Search are overlays. One shared `ScreenHeader` with search and settings on
  every tab. Tabs persist on Settings, hidden on Now Playing and Search.
- **Albums:** sectioned by artist, rows with cover, album title and
  "N tracks · M min", detail hero plus track list.
- **Artists:** circular covers, counts, detail hero plus track list.
- **Search:** borderless field with accent cursor and incremental results.
- **History:** `recordPlay` on selection; Recently played rail shows real plays
  only and hides when empty.
- **Player refinements:** instant track switches, wrap-around swipe on the
  mini-player content only, no bar movement or swipe dismiss, progress snap on
  swipe, floating mini-player card, persistent tabs.
- **Scrollbar:** shared hook/component, active only while scrolling, accent blue,
  draggable, ends level with the mini-player.
- **Demo:** ten tracks across four artists and five albums for the web preview.
- **Settings:** Library (rescan, import, exclude all), Hidden tracks (restore),
  About (version from `app.json`, 0.2.0).

## Build decisions

- Navigation is `AppShell` state, not expo-router, until deep links are needed.
- `plugins/with-media3-exclude.js` excludes the metadata library's Media3 fork
  because it duplicates expo-audio's AndroidX Media3 classes.
- `@expo/vector-icons` was avoided; icons use
  `@react-native-vector-icons/ionicons`.
- Version 0.2.0 (`versionCode` 2). Release `v0.1.0` carries an arm64 debug-signed
  APK; CI release automation is planned separately.
