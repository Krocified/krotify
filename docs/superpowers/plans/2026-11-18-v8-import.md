# v8 Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Import album-sized picks with one copy per file, a determinate progress bar with the current file and a working Cancel, and rows that appear as each file lands.

**Architecture:** The picker stops copying into cache; `pickAndImportTracks` copies once into app storage and reports progress through callbacks. Tags are read for the whole pick in one `getBulkMetadata` call before copying. The row is inserted and reported immediately; the duration probe and embedded-artwork extraction run afterwards and update the row. `AppShell` merges each added/updated record into the visible library without a full rescan.

**Tech Stack:** Expo SDK 58, `expo-document-picker`, `expo-file-system`, `@missingcore/react-native-metadata-retriever`, `expo-audio` (duration probe), React Native `FlatList`.

**Spec:** `docs/spec.md` §v8 — "Import: one copy, honest progress"; §Library management.

## Global Constraints

- Android-first; document picking and SAF copy require a dev build to verify.
- `copyToCacheDirectory: false` for imports. Artwork extraction may still use app storage only.
- Never write to an audio file. Imports copy bytes; metadata lives in SQLite.
- A cancelled import keeps what already landed; nothing is rolled back on cancel.
- No new dependencies.
- Before a task is done: `npm test`, `npx tsc --noEmit`, `npx expo lint` pass.
- Conventional Commits, imperative, under 50 characters, no AI attribution.

## Review Focus

- Picking files with `content://` URIs from a cloud provider must copy and play, not fail on size or copy.
- Cancel pressed mid-import must stop after the current file and leave that file playable, with no partial row.
- A duplicate or hidden file must still emit progress so the count reaches the total.
- A file whose duration cannot be probed must remain playable at 0:00 and must not block the next file.
- A failed artwork extraction must leave the generated cover, never a broken image or a deleted track.

### Task 3: Single copy, progress and deferred metadata

**Files:**
- Modify: `src/imports/local.ts`
- Modify: `src/imports/plan.ts` only if a shared helper is needed (no new decision logic)

**Interfaces:**
- Produces:
  ```ts
  export type ImportOptions = {
    onProgress?: (progress: ImportProgress) => void;
    onAdded?: (record: TrackRecord) => void;
    onUpdated?: (record: TrackRecord) => void;
    signal?: AbortSignal;
  };
  export async function pickAndImportTracks(
    options?: ImportOptions,
  ): Promise<ImportResult>;
  ```

- [ ] **Step 1: Pick without the cache copy**

Change the picker call to `copyToCacheDirectory: false`. Nothing else about the picker changes.

- [ ] **Step 2: Batch the tag read before the loop**

After the pick, call `readTrackSeeds(picked.assets.map((asset) => asset.uri))`. Inside the loop use `seeds.get(asset.uri) ?? {}` instead of `readTrackSeed(copied.uri)`. `seedToTrackPatch` still builds the metadata patch from the seed and the normalized filename.

- [ ] **Step 3: Insert first, then enrich**

For a new file: copy once, verify `copyIsUsable(copied.size)`, insert with `durationMs: 0`, push to `added`, call `options.onAdded?.(record)`, then:

```ts
const durationMs = await probeDurationMs(copied.uri).catch(() => 0);
const seed = seeds.get(asset.uri) ?? {};
const artworkUri = await saveSeedArtwork(copied.uri).catch(() => undefined);
if (durationMs > 0 || artworkUri) {
  await updateTrackFields(record.id, { durationMs, ...(artworkUri ? { artworkUri } : {}) });
  const refreshed = await getTrack(record.id);
  if (refreshed) options.onUpdated?.(refreshed);
}
```

Add `saveSeedArtwork(location: string): Promise<string | undefined>` as a small exported helper in `src/tracks/seed.ts` wrapping the existing `saveHashedArtwork` block, so Task 2's single-file path and this path agree.

- [ ] **Step 4: Emit progress for every asset**

At the top of each iteration call `options.onProgress?.({ index: index + 1, total: picked.assets.length, name })`. Emit it for duplicates, hidden files and failures too, before `continue`.

- [ ] **Step 5: Honour cancel**

At the top of each iteration: `if (options.signal?.aborted) break;`. Cancel never deletes a file that already landed. Keep the existing failure paths.

- [ ] **Step 6: Run checks and a device check**

Run: `npm test && npx tsc --noEmit && npx expo lint`
Expected: PASS. On a dev build, import five files from a `content://` provider, cancel after three: three rows are playable, two are absent, no cache duplicates appear in the storage folder.

- [ ] **Step 7: Commit**

