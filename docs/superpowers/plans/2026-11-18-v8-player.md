# v8 Player Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the player into a stage: two primary controls with everything else behind one expand, a lyrics mode that gives the transcript the screen, and a slow ambient backdrop built from the cover's palette.

**Architecture:** Four small pieces replace the current monolith: `src/lib/ambient.ts` (pure palette and seeded pool math), `AmbientBackdrop` (motion and pause rules), `PlayerTopActions` (heart, lyrics, expand row, sleep panel), and `LyricsStage` (compact header plus transcript with its own overflow). `NowPlayingScreen` keeps layout, transport and the sleep caption.

**Tech Stack:** React Native 0.88 `Animated` with the native driver, `expo-linear-gradient`, `expo-audio` status, `node --test`.

**Spec:** `docs/spec.md` §v8 — "Player controls: two, then more", "Lyrics mode is the lyrics", "Ambient backdrop that moves"; §Visual design system Cover art, Color, Motion.

## Global Constraints

- No new dependencies.
- Cover art itself is never animated, blurred or filtered; only the backdrop moves.
- The ambient loops pause when playback is paused, when the app is backgrounded and when reduce-motion is on.
- Sleep timer is not removed as a feature; it leaves the player's primary row.
- Every pressable has `accessibilityRole` and `accessibilityLabel`; toggles expose `accessibilityState={{ selected }}`.
- Before a task is done: `npm test`, `npx tsc --noEmit`, `npx expo lint` pass.
- Conventional Commits, imperative, under 50 characters, no AI attribution.

## Review Focus

- A track with no real artwork must still get a moving backdrop from its generated hue, never a blank or pure-black screen.
- The same track must look the same on every open; the motion seed cannot use `Math.random()`.
- Reduce-motion must leave the same colors visible, static, not an empty background.
- The expanded action row must collapse on back and on choosing an action, and must not block the transport.
- Lyrics mode with no lyrics must offer one clear path (Import .lrc) and keep Paste reachable from the overflow.

```ts
import { adjustColor, ambientTheme } from '../src/lib/ambient.ts';
import { isHexColor } from '../src/library/palette.ts';

test('adjustColor lightens and darkens and clamps', () => {
  assert.equal(adjustColor('#000000', 1), '#ffffff');
  assert.equal(adjustColor('#ffffff', -1), '#000000');
  assert.equal(adjustColor('#808080', 0), '#808080');
  assert.equal(adjustColor('#zzzzzz', 0.2), '#000000');

test('ambientTheme is deterministic for a seed', () => {
  const input = { seed: 'track:1', coverColor: '#3366AA', hue: 42 };
  assert.deepEqual(ambientTheme(input), ambientTheme(input));
  assert.notDeepEqual(
    ambientTheme(input).pools.map((p) => p.x),
    ambientTheme({ ...input, seed: 'track:2' }).pools.map((p) => p.x),
  );
});

test('ambientTheme stays in range with and without a cover color', () => {
  for (const coverColor of ['#3366AA', null]) {
    const theme = ambientTheme({ seed: 'track:1', coverColor, hue: 42 });
    assert.ok(isHexColor(theme.base));
    assert.ok(isHexColor(theme.top));
    assert.ok(isHexColor(theme.bottom));
    assert.equal(theme.pools.length, 3);
    for (const pool of theme.pools) {
      assert.ok(isHexColor(pool.color));
      assert.ok(pool.size >= 0.9 && pool.size <= 1.6);
      assert.ok(pool.driftX >= -0.25 && pool.driftX <= 0.25);
      assert.ok(pool.durationMs >= 60000 && pool.durationMs <= 120000);
    }
  }
});
```

Run: `npm test -- tests/ambient.test.ts`

- [ ] **Step 3: Implement**

- `adjustColor` parses `#rrggbb`, returns `#000000` for invalid input, and mixes each channel toward `255` when `amount > 0` or `0` when `amount < 0`, rounded and clamped.
- `ambientTheme` uses `coverColor ?? coverColors(hue)[0]` from `src/lib/cover.ts` as `base`, `top = adjustColor(base, 0.18)`, `bottom = adjustColor(base, -0.55)`.
- A local `makeRandom(seed)` seeded by `hashString(seed)` (from `src/lib/hash.ts`) produces a deterministic xorshift stream. Use it for three pools: `size 0.9 + r*0.7`, `x`/`y` in `0..1`, drifts in `±0.25`, `durationMs 60000 + floor(r*60000)`, `delayMs` in `0..durationMs`. Pool colors alternate `adjustColor(base, 0.25)` and `adjustColor(base, -0.25)`.

- [ ] **Step 1: Build the reduce-motion hook**

Subscribe to `AccessibilityInfo.isReduceMotionEnabled()` and its `reduceMotionChanged` event; return the boolean, starting `false` and updating on mount. Clean up the listener.

- [ ] **Step 2: Build the backdrop**

Root `View` with `StyleSheet.absoluteFill`, `pointerEvents="none"`, `overflow: 'hidden'`. Layer 1: `LinearGradient` colors `[`${theme.top}80`, `${theme.base}40`, theme.bottom]` from top to bottom. Layer 2: for each pool, an `Animated.View` positioned at `left: pool.x * width - pool.size * width / 2`, `top: pool.y * height - pool.size * width / 2`, size `pool.size * width`, `borderRadius: size / 2`, `overflow: 'hidden'`, containing a `LinearGradient` from `${pool.color}33` to `${pool.color}00`. Use one `Animated.Value` per pool looping `0 → 1 → 0` over `pool.durationMs * 2` with `delayMs`, translating by `driftX * width` and `driftY * height` and scaling `1 → 1.08`.

- [ ] **Step 3: Pause rules**

Start the loops only when `playing && !reduceMotion`; stop them (and reset to the start pose) otherwise. Subscribe to `AppState` and treat anything other than `active` as paused. When `theme` changes, stop and restart the loops so the next track begins from its own seed. With reduce motion, render the static gradient and the three pools at their start positions.
